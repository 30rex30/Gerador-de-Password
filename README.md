## 📑 Sobre o Projeto

O **Gerador de Passwords** é uma ferramenta focada em privacidade e segurança cibernética. Foi desenhada para combater ataques de força bruta através da criação de credenciais aleatórias, personalizáveis e com alta entropia.

Toda a geração é realizada **100% no lado do cliente (Client-Side)**, garantindo que nenhuma informação ou password gerada saia do teu navegador ou seja enviada para servidores externos.

---

## ✨ Funcionalidades

- 🎛️ **Customização de Tamanho:** Ajusta o comprimento da password entre 6 e 32 caracteres.
- 🔠 **Filtros Personalizados:** Escolhe incluir letras maiúsculas, minúsculas, números e símbolos especiais.
- 📋 **Cópia Instantânea:** Copia a password gerada para a área de transferência com um único clique.
- 📊 **Análise de Força:** Medidor visual dinâmico que indica a robustez da password em tempo real.
- 🔒 **Privacidade Total:** Sem registos, sem base de dados, processamento totalmente local.
- 🎨 **Interface Liquid Glass:** Design moderno em modo escuro com efeito de vidro temperado e animações fluídas no fundo.
