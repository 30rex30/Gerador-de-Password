## 📌 Sobre o Projeto

O **Gerador de Passwords Seguro** é uma aplicação web desenvolvida para facilitar a criação de credenciais fortes, aleatórias e personalizáveis.

Com uma interface moderna e intuitiva, a ferramenta permite gerar passwords adaptadas às necessidades de cada utilizador, combinando diferentes conjuntos de caracteres para aumentar a sua complexidade e resistência a ataques de força bruta.

O projeto foi concebido com uma prioridade fundamental: **a privacidade do utilizador.**

> 🔒 **Privacidade garantida:** Todas as operações são realizadas localmente no navegador. As passwords geradas não são enviadas, armazenadas ou partilhadas com servidores externos.

### 🎯 Objetivos

* Simplificar a criação de passwords seguras.
* Incentivar boas práticas de segurança digital.
* Garantir uma experiência rápida e intuitiva.
* Eliminar a necessidade de serviços externos para gerar credenciais.
* Disponibilizar uma ferramenta leve, gratuita e acessível.

## 🛡️ Segurança e Privacidade

A segurança é um dos pilares fundamentais deste projeto.

Ao contrário de ferramentas que dependem de serviços externos, o Gerador de Passwords Seguro foi concebido para funcionar diretamente no navegador do utilizador.

**Princípios de segurança:**

* **Processamento local:** nenhuma password é transmitida para servidores externos.
* **Sem registo de dados:** não existe recolha de passwords geradas.
* **Sem dependências de backend:** não é necessário criar contas ou autenticar-se.
* **Controlo do utilizador:** todas as opções de geração são definidas localmente.
* **Código transparente:** a aplicação pode ser analisada e auditada por qualquer pessoa.

> Nota: A segurança de uma password depende também do comprimento, da aleatoriedade e da forma como é armazenada e utilizada. A ferramenta não substitui um gestor de passwords.

## 🚀 Instalação e Execução

Não precisas de instalar Node.js, configurar bases de dados ou utilizar ferramentas de compilação.

Segue os passos abaixo para executar o projeto localmente.

### 1. Clonar o repositório

```bash
git clone https://github.com/30rex30/Gerador-de-Password.git
```

### 2. Entrar na pasta do projeto

```bash
cd Gerador-de-Password
```

### 3. Executar a aplicação

Abre o ficheiro `index.html` diretamente no teu navegador.

**E já está!** A aplicação encontra-se pronta a utilizar.
